# Aurèle

A fictional Geneva watch maison built as a zero-cost showpiece: a procedural real-time 3D watch (three.js) that comes apart as you scroll and shows the visitor's own time. Black, ivory and gold; three references (yellow gold and green, steel and black, rose gold and ivory). No paid APIs, assets or accounts.

The site is in [`aurele/`](aurele).

## Run

```bash
cd aurele
npm install
npm start
```

Then open http://localhost:4174. See [`aurele/README.md`](aurele/README.md) for edit notes.

Aurèle is fictional and nothing is for sale.
