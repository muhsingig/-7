# Watch showpiece sites

Two fictional watch brands built as zero-cost showpieces: a procedural real-time 3D watch (three.js) that comes apart as you scroll and shows the visitor's own time. No paid APIs, assets or accounts.

| Folder | Concept |
| --- | --- |
| [`aurele/`](aurele) | Maison style: black, ivory and gold, three references. Run on port 4174. |
| [`prahar/`](prahar) | The first version: eight "prahars" of the day, ragamala paintings, colourful themes. Run on port 4173. |

## Run

In either folder:

```bash
npm install
npm start
```

Then open the printed address. Each folder's README has the edit notes.

Aurèle and Prahar are fictional and nothing is for sale. Prahar's paintings are public domain (CC0) from the Art Institute of Chicago; credits are in `prahar/assets/img/credits.json`.
